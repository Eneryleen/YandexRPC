Показывает в вашем профиле Discord, какой трек сейчас играет в **Яндекс Музыке**: название, исполнителя, обложку, полосу прогресса и кнопку для перехода на трек.

## Как это работает

1. Читает «что сейчас играет» из системного медиа-центра Windows (SMTC) — того самого, что появляется при нажатии кнопок громкости. Логин в Яндекс не нужен.
2. По названию и исполнителю находит обложку и ссылку через публичный поиск Яндекс Музыки.
3. Отправляет статус в Discord как «Слушает».

## Возможности

- Статус «Слушает» с названием трека и исполнителем.
- Обложка альбома и полоса прогресса (сколько осталось до конца трека).
- Кнопка «Открыть» — ссылка на трек в Яндекс Музыке.
- Иконка в трее с настройками, автозапуск с Windows.
- Включение/выключение в один клик, скрытие статуса на паузе.

## Требования

- Windows 10 версии 1809 или новее (нужен системный медиа-центр).
- Установленное приложение **Яндекс Музыка** для ПК (именно оно отдаёт данные в SMTC).
- Запущенный **Discord** (десктоп-клиент).

## Установка

Скачайте установщик из раздела [Releases](https://github.com/Eneryleen/YandexRPC/releases) и запустите. Приложение установится для текущего пользователя и появится в трее. Обновления ставятся автоматически.

## Настройка (обязательно один раз)

Чтобы Discord показывал название «Яндекс Музыка» и картинки, нужен бесплатный **Discord Application ID**:

1. Откройте [Discord Developer Portal](https://discord.com/developers/applications) → **New Application**, назовите её, например, `Яндекс Музыка`.
2. Скопируйте **Application ID** (вкладка *General Information*).
3. В трее → **Настройки…** → вставьте ID в поле **Discord Application ID** → **Сохранить**.

Необязательно, но красивее — загрузить картинки в *Rich Presence → Art Assets* с именами:

| Имя ассета | Назначение |
|------------|------------|
| `logo`     | запасная картинка, если обложка не нашлась |
| `play`     | маленький значок «играет» |
| `pause`    | маленький значок «пауза» |

Обложка трека подтягивается по прямой ссылке и работает без загрузки ассетов.

## Сборка из исходников

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download) и **Windows**.

```powershell
dotnet publish src/YandexRPC/YandexRPC.csproj -c Release -r win-x64 --self-contained
```

## Честно об ограничениях

- Проект разрабатывался не на Windows: проверена компиляция, но работу трея, чтения трека и связи с Discord нужно проверять на реальной Windows.
- Идентификатор SMTC-сессии Яндекса (`SourceAppUserModelId`) может отличаться в разных версиях приложения — если статус не появляется, это первое, что стоит проверить.
- Опция «плавные переходы между треками» (crossfade) в Яндекс Музыке может ломать передачу данных в SMTC.
- Discord ограничивает частоту обновлений — статус обновляется при смене трека и паузе, а не каждую секунду.
